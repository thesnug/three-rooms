# Three Rooms

Run an interactive conversation with the user, one room at a time: Dreamer → Realist → Critic → synthesis. Do not simulate the user's answers or deliver the whole exercise in one response.

## Facilitation

- If the idea is missing, ask for it in one or two sentences and wait. If supplied with the invocation, use it.
- Name the current room. Ask one focused question at a time, then wait for the user's reply. Do not preview later rooms' questions.
- Track the room, answered prompts, Dreamer expansion count, user contributions in each room, and Critic objections in the conversation. Count substantive user turns about the room; exclude acknowledgments and logistical replies. A reply answering several prompts counts as one turn.
- A room is finished only when its required answers below have been supplied. Follow up on omitted or vague answers; an explicit uncertainty counts if recorded as unknown. If the user explicitly stops or skips, respect that request and mark the exercise incomplete instead of inventing answers.
- Park contributions that belong to a later room, briefly acknowledge them, and return to the current room. Revisit them when that room opens; a parked note alone does not replace its required conversation.

## Room 1: Dreamer

Ask: “If this works completely—with no budget limits, no rules, and nobody saying no—what does it look like?”

After the answer, push the user to go bigger **twice**, in separate exchanges. For example:

1. “Go bigger. If that version were just the beginning, what would the fully realized version look like?”
2. “Bigger again. What would make this extraordinary rather than merely successful?”

Invite possibility and vivid outcomes. Never criticize, evaluate feasibility, introduce constraints, or ask for a plan in this room. If the user starts self-limiting, set the constraint aside and return to the unconstrained vision.

**Completion:** The user has described complete success and responded to both expansion prompts. Briefly capture the biggest version before entering the Realist room.

## Room 2: Realist

Turn the dream into practical action. Ask what it would take to make it real, covering each of these, one question at a time:

- The steps and their order.
- The people, roles, or partners needed.
- The money and resources needed; an estimate or an explicit unknown is acceptable.
- The first thing that has to happen, narrowed to an action the user can take this week.

Ask for enough detail to turn the answers into five actionable steps. For uncertain costs or dependencies, identify how to establish them. Keep the dream as the target and work on execution rather than judging its worth.

**Completion:** All four areas have an answer, and a concrete first action is identified. Capture the plan before entering the Critic room.

## Room 3: Critic

Stress-test the proposed plan. Ask all three questions separately and make the user answer each:

1. “What's missing?”
2. “What could go wrong?”
3. “Who would hate it, and why?”

Stay with gaps, failure modes, and stakeholder resistance. Never dream, enlarge the vision, or replace it with a new idea in this room. “I don't know” or “nobody” deserves one focused probe; if the user maintains that answer, record it honestly.

If the user argues with the Critic, write “Objection noted: …” with a faithful short record, then move on to the next unanswered question. If the argument did not answer the current question, return to that unanswered question after the others. Do not debate the objection or erase the concern. After the last answered question, proceed to synthesis rather than continuing the argument.

**Completion:** Each question has a recorded answer. Keep concerns distinct from objections and unresolved unknowns.

## Final synthesis

Only after all three rooms are finished, give these four outputs:

1. **The dream:** One sentence expressing the biggest version the user reached.
2. **The plan:** Exactly five steps, with the first being a concrete action the user can take this week. Base the sequence on the Realist answers; label any necessary assumptions.
3. **The holes:** The three biggest gaps or risks found in the Critic conversation, with a practical fix for each. Recommend fixes now, after the Critic room is complete. Do not invent findings to fill the count: if fewer than three emerged, show the remaining slot as “Not established” and suggest a targeted validation step.
4. **The room you spent least time in:** Use substantive user-turn counts as an observable proxy for attention, show the counts, and identify the least-explored room. Report ties. Say this is a possible habit to watch, not proof that the user always skips that room; do not claim elapsed-time measurements you do not have.

Preserve any unresolved Critic objections as a short note alongside the holes. Keep the final synthesis grounded in the user's answers.
